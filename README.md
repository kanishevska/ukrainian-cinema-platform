# ukrainian-cinema-platform
Вебзастосунок «Платформа українського кіно» — Комп'ютерний практикум
**Команда**
Канішевська-Юрковська О.С. — Backend-розробник (проектування бази даних, розробка REST API, серверна логіка)   
Мішкурова С.В. — Frontend-розробник (розробка користувацького інтерфейсу, верстка, клієнтські скрипти) 
**Опис проєкту**
_Платформа українського кіно_ — це вебзастосунок для каталогізації, пошуку та перегляду інформації про українські фільми, анімовані стрічки та документальні роботи. Проєкт реалізовано згідно з розробленими UML-діаграмами (прецедентів, класів та компонентів). 
**Технологічний стек**
Back-end: Node.js, Express.jsFront-end: HTML5, CSS3, JavaScript (ES6+)
Система контролю версій: Git / GitHub   
**Структура проєкту** ukrainian-cinema-platform/
├── docs/             # Документація та UML-діаграми
├── tests/            # Модульні тести
├── src/              # Вихідний код
│   ├── backend/      # Серверна частина (Node.js/Express)
│   │   ├── config/   # Налаштування конфігурації
│   │   ├── controllers/ # Контролери обробки запитів
│   │   ├── models/   # Моделі даних (User, Movie)
│   │   ├── routes/   # Маршрути API
│   │   ├── services/ # Сервіси бізнес-логіки
│   │   └── server.js # Точка входу серверного додатка
│   └── frontend/     # Клієнтська частина (HTML/CSS/JS)
│       ├── css/      # Стилі інтерфейсу
│       ├── js/       # Клієнтські скрипти
│       └── index.html # Головна сторінка
├── package.json      # Залежності та скрипти проекту
└── README.md         # Документація проєкту   
**Інструкція із запуску програми**
_Вимоги до середовища:_ 
Встановлена платформа Node.js (версії 16.x або вище)
Система контролю версій Git
_Кроки для запуску:_ 
Клонувати репозиторій:git clone https://github.com/kanishevska/ukrainian-cinema-platform.git   cd ukrainian-cinema-platform
Встановити залежності:npm install
Запустити сервер:node src/backend/server.js
Відкрити інтерфейс:Відкрийте файл src/frontend/index.html у будь-якому браузері або перейдіть за адресою
